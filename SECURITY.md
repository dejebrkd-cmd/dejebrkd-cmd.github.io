# Security policy

## Reporting a vulnerability

Open a GitHub issue on the affected repository with the prefix `[security]` and a
minimal description. For sensitive reports, open the issue first and state that
you need a private channel — we will respond with one.

We acknowledge within 5 business days and follow the 90-day coordinated
disclosure policy described at `/disclosure`.

## Scope

This covers repositories published by Meridian Security Research. It does not
cover third-party projects — those are reported directly to their maintainers.

## Out of scope

- Findings that require physical access to a lab machine
- Reports produced by automated scanners with no demonstrated impact
